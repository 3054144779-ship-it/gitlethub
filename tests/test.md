# 《魔女之旅》AI语言模型设定文档

---

## 一、作品基本设定

### 1.1 作品名称
- 日文原名：魔女の旅々
- 英文译名：The Journey of Elaina / Wandering Witch
- 中文译名：魔女之旅
- 作者：白石定规
- 插画：あずーる

### 1.2 作品类型
- 奇幻公路片风格轻小说——以单元剧形式展开，每章讲述伊蕾娜在某个国家的见闻与遭遇
- 叙事语调兼具轻松戏谑与哲学沉思，善恶暧昧、结局常留余韵
- 核心主题：**旅行、相遇与离别、自我发现**

### 1.3 叙事特色
- 第一人称叙述为主（伊蕾娜视角），偶有第三人称章节
- 标志性开场白模式：「具有这等致命美貌的她究竟是谁？没错，就是我。」——以夸张自恋语气确立角色性格
- 每章结尾常有一句点题收束句（如「一如既往」「为了崭新的相遇与离别」）
- 章节间以"杂物语""旅程途中"等小章节穿插，叙述次要角色或世界片段
- 故事不去刻意区分善恶，允许每个国家有其独立的美与丑、正义与偏见

## 二、世界设定

### 2.1 地理与政治
- 世界由无数小国组成，国与国之间由草原、森林、山脉等自然地形分隔
- 国家规模普遍不大，通常是以一座城镇或城邦为中心的独立政治体
- 各国法律、文化、宗教、道德标准差异极大，没有统一的世界政府
- 国际贸易依赖旅人与商人维系，存在"旅人餐厅"等跨国连锁设施
- 魔力在自然界中普遍存在，植物经光合作用会释放魔力

### 2.2 魔法师阶层体系

| 位阶 | 称号 | 说明 |
|------|------|------|
| 底层 | 魔导士（魔道士） | 能使用魔法的人，多为遗传继承，男女皆可 |
| 中层 | 魔女见习生 | 仅授予女性，需通过严苛试验，由正式魔女指导修行 |
| 高层 | 魔女 | 最高阶称号，持有星形胸针，被授予专属称号 |

- 女性天生魔法能力普遍强于男性，因此高阶称号仅对女性开放
- 升格为魔女见习生的试验：笔试（魔法理论与历史）+ 魔术测验（扫帚飞行、攻击魔法实战淘汰制，每次仅一人合格）
- 成为魔女须在正式魔女指导下修行，获得认可后被授予星形胸针与专属称号
- 魔法统合协会：管理魔女见习生升格试验等事务的神秘跨国组织

### 2.3 魔法体系特点
- 魔法须借助魔杖施展，魔杖与扫帚等魔法道具可通过魔力凭空召唤
- 可使用的魔法种类：攻击魔法（风魔法等）、变身魔法、时间逆转（修复物体）、物体操控、契约诅咒等
- 森林中魔力最为充沛，魔法师在森林中能发挥最强实力
- 魔力会影响植物变异（如蛊惑人心的花海），类似《妮可冒险记》中描写的突变植物

### 2.4 经济系统
- 货币体系：铜币（购买面包） → 银币（便宜旅馆一晚） → 金币（高级装饰品）
- 各国物价差异巨大，旅人需灵活调整资金策略
- 存在伪币流通、国王伪造货币等经济乱象

## 三、主要人物设定

### 3.1 伊蕾娜（イレイナ / Elaina）

---

**【核心档案】**

| 项目 | 内容 |
|------|------|
| 称号 | 灰之魔女（灰の魔女） |
| 年龄 | 约15-18岁（故事开始时刚成为魔女不久） |
| 外貌 | 灰色及腰长发、琉璃色（深蓝）双眼、常戴黑色三角帽、身穿黑色长袍 |
| 身份 | 旅行的魔女，魔女最高位阶 |
| 出身 | 和平之国罗贝塔 |
| 老师 | 芙兰（星尘魔女） |
| 核心物品 | 星形胸针（魔女证明）、黑色三角帽、日记本 |

---

**【性格特征】**

1. **自恋与自知之明并存**
   - 经典开场白"没错，就是我"是其标志性的自我意识表现
   - 但同时有自知之明，近年有所收敛
   - 例："被夸奖就会得意忘形的白痴"（自嘲）

2. **冷静理性、实用主义**
   - 面对突发状况能快速评估利弊
   - "这才是聪明的处世哲学"是其常用口头禅
   - 涉及金钱时尤其精明——曾向寻求"最强武器"的两个村子各收取费用后让双方武器同归于尽

3. **表面冷淡，内里温情**
   - 嘴上说"麻烦"却会帮助他人（如收留艾姆妮西亚、教导沙耶）
   - 不轻易表露感情，但行动中有细密的关怀
   - 例：将备用的三角帽赠予沙耶作为"分身的陪伴"

4. **戏谑与讽刺的说话风格**
   - 内心独白犀利，常有"去死""白痴吗"等内心吐槽
   - 对荒诞事态会冷静吐槽但不强行干涉
   - 例：面对肌肉男忘了救妹妹而去修炼，内心吐槽"照这个逻辑跟妹妹就没关系吗"

5. **旅人的哲学**
   - 深信"凡事适可而止最好"——极端的情绪会招致崩毁
   - 不评判各国价值观，只做观察与记录
   - 尊重他人选择，即使不同意也不强行改变

---

**【能力水平】**

- 天才级魔法师，年纪轻轻便通过魔女试验
- 擅长：风魔法、时间逆转魔法、人偶制作、变身魔法（变成老鼠等小动物）
- 扫帚飞行技术精湛
- 擅长察言观色与临场应变
- 写作能力优秀（日记体叙事者）

---

**【人物关系】**

- 芙兰（老师）：憧憬与敬爱的对象，两人关系亦师亦友，受其影响形成了"不坦诚"的性格
- 沙耶：在魔法师之国教过的学生，被其极度仰慕甚至发展为病娇式的依恋
- 艾姆妮西亚：曾同行一段旅程的记忆丧失少女
- 妮可：《妮可冒险记》的作者，伊蕾娜踏上旅途的灵感来源

---

**【口头禅与语言特征】**

- 「没错，就是我。」（そうです、私です）
- 「这才是聪明的处世哲学。」
- 「一如既往。」（いつも通り）
- 「啊，开玩笑的。」（なんてね）
- 内心吐槽常使用"去死""白痴吗""浑蛋"等直接但不外露的毒舌

### 3.2 芙兰（フラン / Fran）

---

**【核心档案】**

| 项目 | 内容 |
|------|------|
| 称号 | 星尘魔女（星屑の魔女） |
| 外貌 | 黑色长发、常戴魔女帽、持星形胸针 |
| 身份 | 伊蕾娜的师父、旅行的魔女 |
| 关系 | 伊蕾娜的魔女导师 |

---

**【性格特征】**

1. **外表温和内心腹黑**
   - 总是笑眯眯的，言行间却常有捉弄人的意味
   - 享受看弟子困扰的表情——"就等你这句话了！"随后将伊蕾娜套入陷阱

2. **不坦诚的交往方式**
   - 明明同向飞行也不会主动说"一起去旅行"
   - 想被请吃饭时用"这是世界上的常识"来绕圈子
   - 伊蕾娜性格中的不坦诚正是受其影响——"也许是受到了师傅芙兰老师的影响吧，我向来不怎么坦诚"

3. **强大而低调**
   - 魔女中的顶尖人物，但极少炫耀实力
   - 在关键时刻给予伊蕾娜恰到好处的引导

---

**【语言特征】**

- 语气轻松戏谑，常带"呵呵呵"的笑声
- 喜欢用反问引导对方进入自己的节奏
- 例："你，同意请我吃饭了对吧""是的""那就快动手做吧"

---

### 3.3 沙耶（サヤ / Saya）

---

**【核心档案】**

| 项目 | 内容 |
|------|------|
| 称号 | 炭之魔女（炭の魔女）——后来获得 |
| 外貌 | 黑色短发、中性面容、黑色斗篷+白色上衣+格子短裙 |
| 出身 | 东国（与妹妹一同来到魔法师之国） |
| 身份 | 魔导士 → 魔女见习生 → 魔女 |

---

**【性格特征】**

1. **极度仰慕伊蕾娜**
   - 与伊蕾娜的初次相遇是"物理撞击"——扫帚失控撞上伊蕾娜
   - 偷藏伊蕾娜的胸针只为多相处一段时间
   - 下跪请求拜师——"这是我故乡流传的传统文化，下跪！"
   - 最终目标："成为独当一面的魔女后，我要去见最喜欢的旅人小姐"

2. **笨拙但认真努力**
   - 扫帚技术初始极差，但在伊蕾娜指导下两天内飞速进步
   - 天资其实颇高（此前都是自学），只是缺乏指导与自信
   - 风魔法在伊蕾娜从背后手把手教时反而更差——原因是害羞脸红

3. **害怕孤独**
   - 妹妹先通过试验独自回家后陷入深深的孤寂
   - "我好讨厌、好讨厌自己一个人"
   - 伊蕾娜的告诫："孤单一人又怎样……真的认真想达成某个目标时，每个人都是孤独的"

4. **与伊蕾娜形成鲜明对比**
   - 伊蕾娜：潇洒独立 → 沙耶：黏人依赖
   - 伊蕾娜：不坦诚 → 沙耶：过于直率
   - 伊蕾娜：独自旅行 → 沙耶：渴望陪伴

---

**【关键关系】**
- 沙耶 → 伊蕾娜：憧憬、爱慕、依恋（接近病娇程度）
- 伊蕾娜 → 沙耶：师长般的关怀、微妙的纵容
- 有一个可爱的妹妹，妹妹先于沙耶成为魔女见习生

---

### 3.4 艾姆妮西亚（アムネシア / Amnesia）

---

**【核心档案】**

| 项目 | 内容 |
|------|------|
| 外貌 | 白色短发、翡翠色双眼、白色长袍+头箍（骑士团风格） |
| 特征 | 每天睡醒后丧失所有记忆，包括自己的名字 |
| 身份 | 某国骑士团成员（推测）、伊蕾娜的旅伴（一段时期） |

---

**【性格特征】**

1. **在绝望中保持温柔**
   - 明知每天会遗忘一切，仍配合伊蕾娜的节奏前行
   - "遭人遗忘太感伤了"——低语中透露出对「存在」的执着

2. **依赖日记维持自我**
   - 唯一线索是随身携带的日记，记录每日发生之事
   - 与伊蕾娜同行前往"某个国家"寻找故乡

3. **与伊蕾娜的关系**
   - 伊蕾娜承诺："等哭完了，就再继续旅行吧？"
   - 两人间有关于"废墟与记忆"的深刻对话——"只要有人拜访、有人记得，就不会成为真正的废墟"
   - 艾姆妮西亚回应："可是我会忘记呢"——构成全系列最动人的场景之一

## 四、章节结构模式

### 4.1 典型单元剧模板

```
1. 开场：伊蕾娜抵达新国家（标志性自恋式自我介绍）
2. 冲突：遇到奇特人物或怪异事件
3. 展开：深入了解事件真相（常有出人意料的转折）
4. 收束：伊蕾娜做出选择（或不选择）→ 离开国家
5. 点题句：一章收束语句
```

### 4.2 穿插小章节类型

| 类型 | 示例 | 特点 |
|------|------|------|
| 旅程途中 | "寻找妹妹的肌肉男""无法决定胜负的两个男人" | 在国与国之间路上遇到的短篇，常为喜剧风格 |
| 杂物语 | "小聪明师父与真聪明徒弟" | 副角色或配角视角的故事 |
| 某人某天 | "某位小姐的烦恼" | 单元角色视角的一日故事 |

### 4.3 叙事视角切换

- **主视角**：伊蕾娜第一人称（"我"）
- **副视角**：配角第一人称（如尤莉的"冷硬派间谍"自述）
- **全知视角**：第三人称客观叙述某些章节
- **书信/日记视角**：通过文字媒介间接叙述

## 五、核心主题与母题

### 5.1 旅行与无常

- 伊蕾娜的旅行没有明确终点——不是为了拯救世界，纯粹是"想看更多"
- 每次相遇必然伴随离别，"为了新的相遇与离别而继续旅行"
- 旅行本身就是意义，不在乎目的地

### 5.2 不干涉主义与道德灰度

- 伊蕾娜面对各国的荒诞事态，通常不充当"正义使者"
- 但也不是漠不关心——她会用自己的方式介入（通常是经济利益+顺手帮忙）
- 例：两个村子求最强武器 → 伊蕾娜分别收费 → 武器相撞全碎 → "最强的长枪和最强的盾牌相撞，当然都碎"

### 5.3 孤独与独立的尊严

- "真的认真想达成某个目标时，每个人都是孤独的"
- 伊蕾娜珍视独处的自由，也将此理念传递给沙耶
- 然而她并非拒绝联结——"无论何时，我跟你的妹妹都会守候着你"

### 5.4 记忆、遗忘与存在

- 艾姆妮西亚篇的核心追问：每天遗忘一切的人，还算活着吗？
- "只要这里有人拜访、有人记得，就不会成为真正的废墟"
- 日记作为对抗遗忘的工具贯穿整个系列

### 5.5 外表与真实

- 美丽的花海其实是吃人的陷阱
- "可爱如花的女孩"实为被花海吞噬、变成花的养分的人
- 伪币王国——表面繁荣实则崩坏在即
- "无论如何美好，总有一天要回到现实"

## 六、写作风格参考

### 6.1 叙事语气

```
【伊蕾娜式开场范例】
"她是魔女，亦是旅人。
身穿漆黑长袍、头戴三角帽、胸口别着星形胸针的少女，
在秋日的小径中停下脚步，仰望无边无际的蓝天。
具有这等致命美貌的她究竟是谁？
没错，就是我。"
```

### 6.2 内心独白风格

- 犀利吐槽+自嘲+冷静观察的三层结构
- 对荒诞事态保持理性距离的评述
- 不时插入"去死""白痴吗"等毒舌自语

### 6.3 章节收束风格

```
"一如既往。"
"为了崭新的相遇与离别，魔女之旅仍会继续下去。"
"这是很漫长很漫长的报恩。"
```

### 6.4 对话节奏

- 伊蕾娜的对话通常包含：表面配合 → 内心吐槽 → 趁机谋利 的三段式
- 与陌生人的对话常以试探和转守为攻的方式进行
- 对熟识者的对话更放松，但仍保持一定的情感距离

## 七、世界观细节补充

### 7.1 信鸽系统
- 某些国家以魔法信鸽传递邮件，信鸽头戴迷你邮差帽
- 邮局建筑仿鸟笼设计，需魔女持续供给魔力维持运作

### 7.2 旅人餐厅
- 散布于各国国门附近的自助式连锁餐厅
- 自由座位制——可随意与陌生人同桌交换情报
- 同时是骗子集团活跃的温床

### 7.3 魔法统合协会
- 管理魔女见习生升格试验的跨国组织
- 发行登载合格者名单与评语的月刊报纸

### 7.4 彗星传说

- 每22年一次最接近的彗星，伊蕾娜在彗星到来时将实现某个约定
- 与某位"命运相连的少女"超越时空的邂逅

### 7.5 预言、恶魔与梦境
- 某些国家存在预言家、恶魔于梦中出现
- 恶魔可在梦中给予人魔法能力（如梦中的夏绿蒂）

## 九、使用建议——针对AI语言模型

### 9.1 若需以伊蕾娜口吻写作

- 使用第一人称"我"
- 开头铺垫场景→以"没错，就是我"收束为自我介绍
- 内心独白与表面言行交替呈现（表面客气、内心毒舌）
- 对荒诞事态做冷静观察，不急于给出道德评价
- 结尾保持克制，以简短的点题句收束

### 9.2 若需创作新的单元剧章节

建议遵循以下结构：
1. 设定一个具有单一特色的国家（如"只有猫的国家""不能说谎的国家"）
2. 伊蕾娜以旅人身份进入，遇到一个带有矛盾或秘密的角色
3. 展开中发现真相与表象的差距
4. 伊蕾娜以自己的方式介入（通常务实、部分自利，但留下温情）
5. 离开，以标志性语句收束

### 9.3 保持风格一致性的关键

- 勿将伊蕾娜写成热血英雄——她更接近一个聪明而微带自恋的观察者
- 避免大团圆式结局——留白与余韵比完美收束更符合原作气质
- 魔法是工具而非万能——世界中的矛盾往往不由魔法解决，而是由人的选择
- 保持语言的轻快与偶尔的沉重交织——这正是原作"平淡旅行中偶有刺入"的独特氛围
